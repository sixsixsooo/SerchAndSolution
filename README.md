# Комплект — ИИ-помощник по подбору товаров

**Проект для участия в Региональной премии Ростовской области в сфере искусственного интеллекта.**  
Предполагаемая номинация: **«Студенты вузов»**.

## О проекте

«Комплект» — прототип ИИ-помощника, который помогает подобрать один товар или набор товаров под запрос человека. Пользователь описывает задачу обычным русским языком, а система извлекает ключевые условия, задаёт уточняющие вопросы и формирует подходящие варианты из структурированного каталога.

При подборе учитываются город, общий бюджет, состав комплекта, характеристики и ограничения по отдельным товарам. Если данных недостаточно, помощник уточняет их. Если подходящего комплекта нет, объясняет причину.

## Практическая задача

Подбор нескольких товаров требует сопоставления характеристик, проверки ограничений и расчёта общей стоимости. «Комплект» объединяет эти действия в одном диалоге: пользователь формулирует потребность естественным языком, а система преобразует её в проверяемые условия и подбирает согласованный набор.

Текущий демонстрационный каталог содержит примеры для Таганрога, Ростова-на-Дону и Азова.

## Что реализовано в прототипе

- диалоговый интерфейс на русском языке;
- разбор запроса и истории диалога;
- уточнение недостающих условий;
- фильтрация и ранжирование товаров по структурированным данным;
- расчёт общей стоимости и проверка бюджета;
- объяснение причин выбора или отсутствия подходящего комплекта;
- демонстрационный поиск по изображению;
- автоматизированные проверки логики и сценариев работы.

Это программный прототип с демонстрационным каталогом, а не действующая торговая площадка. Покупка и оплата в приложении не выполняются.

## Роль искусственного интеллекта

ИИ применяется для интерпретации пользовательских формулировок и контекста диалога: система преобразует свободный текст в набор условий, пригодных для последующей проверки.

Подбор товаров, проверка бюджета, сопоставление характеристик и расчёт итоговой стоимости выполняются программной логикой по структурированным данным каталога. Это позволяет не поручать языковой модели арифметику и окончательную проверку ограничений.

В целевой конфигурации планируется использовать **GigaChat**. В текущей редакции изменено позиционирование проекта и подготовлена документация; фактическое подключение и проверка GigaChat API относятся к следующему техническому этапу.

## Запуск демонстрации

Требуются Python 3.10+ и Node.js LTS для запуска через npm. Внешние Python-пакеты для базового запуска не требуются.

```bash
npm run dev
```

Либо:

```bash
python3 -m buyer.demo
```

Откройте адрес `http://127.0.0.1:8765`, который будет выведен в терминале.

## Структура

| Путь | Назначение |
| --- | --- |
| `buyer/` | диалог, разбор запроса, подбор и демонстрационный сервер |
| `buyer/ui/` | веб-интерфейс |
| `data/` | демонстрационный каталог, категории и города |
| `schemas/` | схемы входных и выходных данных |
| `examples/` | примеры запросов |
| `tests/` | автоматизированные проверки |
| `llm/` | клиент и шаблон конфигурации языковой модели |

## Ограничения текущего прототипа

- каталог ограничен демонстрационными категориями и городами;
- актуальность и полнота каталога зависят от источника данных;
- результаты языковой модели требуют контроля;
- интеграция с GigaChat, включая авторизацию и проверку сетевых сценариев, ещё должна быть выполнена;
- поиск по фото зависит от локально подготовленной модели и соответствующих файлов.

## Дальнейшее развитие

1. Подключить и протестировать GigaChat.
2. Расширить каталог и перечень поддерживаемых категорий.
3. Подготовить методику тестирования качества разбора запросов и подбора.
4. Провести апробацию на пользовательских сценариях в Ростовской области.
5. Зафиксировать измеримые результаты: точность извлечения условий, долю корректных подборок, время выполнения и оценку удобства пользователями.
